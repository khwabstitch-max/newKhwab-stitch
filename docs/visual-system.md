# Boutique visual system

Tokens live in `client/src/tokens.css`; common refinements in `review-ui.css` extend the established layouts. The supplied KS logo, garment photographs and existing identity remain. Ivory canvas, deep teal primary actions, restrained champagne borders/accents and charcoal text unify public, account, request, admin, worker and support views. Existing copper/chocolate branding remains a secondary identity accent.

The body stack uses system-ui/Segoe UI with Nirmala UI/Mangal and sans-serif fallbacks for Devanagari. Georgia is the one complementary heading serif with fallbacks. These are locally available system-font references, not redistributed font files or a claim that Georgia is open-source. No font download or third-party font request is introduced. Microsoft's [font redistribution FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq) permits referencing Windows fonts in CSS font stacks; it distinguishes that from copying/converting the files for web hosting. This project only references installed fonts. Hindi can fall back without blocking text rendering.

Central variables cover color, typography, spacing, borders/radii, shadows, focus and responsive intentions. Shared controls use visible focus, disabled/error states,44 px touch targets and reduced-motion behavior. CSS media queries apply the documented mobile/tablet widths; CSS custom properties cannot replace media-query conditions. Cards use explicit selected states, native radio/checkbox semantics and image alternatives. Multi-view previews are separate buttons with keyboard dismissal/focus return. Low-resolution supplied detail images are contained; larger previews do not imply added source detail.

Chrome checks cover320/390/768/1440 widths for the branching request flow, public/catalogue/account routes and relevant admin/support views. These checks catch overflow and interaction regressions, not a full assistive-technology or every-device certification. Manual screen-reader review remains useful before launch. No decorative animation, stock garment replacement or excessive font payload was added.
